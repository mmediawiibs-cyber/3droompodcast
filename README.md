# VoxCast 3D — Orthographic Podcast Studio Designer

Interactive 3D orthographic podcast studio room designer built with Three.js and Tailwind CSS.

## Features
- **3D Orthographic Isometric Room**: Orbit, pan, zoom, and switch between isometric & top-down camera angles.
- **Room Resize Tool**: Dynamically adjust room width (5m–14m), depth (5m–14m), and ceiling height (3m–6m) or choose quick studio size presets.
- **Movable Furniture & Studio Gear**: Drag, rotate, clone, delete, and recolor podcast desks, chairs, sofas, gear racks, plants, standing mics, acoustic baffles, 4K cinema cameras, and phone+tripod rigs.
- **Live Multi-Camera & Phone Monitor Dock**: Real-time perspective viewfinders on the right panel that automatically expand as you add more cameras or phones, featuring Portrait (9:16) / Landscape (16:9) switching, Long Lens (18mm–200mm) focal length controls, Zoom (1.0x–3.0x), and Tilt Pitch.
- **24-Hour Solar Time-of-Day Changer**: Scrub through sunrise, daylight, golden hour, and moonlight with window blinds and automated time-lapse.
- **Customizable Studio Lighting Rig**: Movable 3D Key Softboxes, RGB Neon Tube floor bars, ceiling dome light, and glowing "ON AIR" neon sign.

## How to Run Locally or Publish on GitHub Pages
1. Upload `index.html` and `README.md` to a GitHub repository.
2. Go to **Settings → Pages** in your repository.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` (root `/`), and click **Save**.
